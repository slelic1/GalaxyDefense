# 🚀 Galaxy Defense: 행성 수호전

외계 함대의 침공으로부터 행성 본부를 지키는 HTML5 + Canvas 기반 타워 디펜스 게임입니다. 이 프로젝트는 데스크톱과 모바일에서 동작하도록 설계되었으며, 최근 다음과 같은 기능들이 추가/개선되었습니다.

[![Play Game](https://img.shields.io/badge/PLAY-Galaxy%20Defense-00f0ff?style=for-the-badge&logo=googlechrome)](https://slelic1.github.io/GalaxyDefense/)

---

## ✨ 핵심 업데이트 & 현재 기능
- 모바일 뷰포트 보정: 브라우저 주소창/크롬 변화에 대응하기 위해 JS에서 --app-height를 설정하여 화면 잘림을 최소화했습니다.
- 안전영역(safe-area-inset) 지원: 하단 HUD가 iOS 기기에서 가려지지 않도록 보정했습니다.
- 포탑 확장: 총 9종의 포탑 제공(펄스 레이저, 플라즈마, 미사일, EMP, 수리 드론, 레일건 스나이퍼, 테슬라 코일, 화염방사기, 빙동 포탑).
- 레벨 시스템: 포탑은 Lv.1~Lv.10까지 업그레이드 가능. 레벨이 오르면 데미지/사거리/이펙트/투사체가 점진적으로 강화됩니다.
- 업그레이드 임팩트: 레벨업 시 시각 이펙트(스파크/폭발/쇼크웨이브)와 사운드로 체감형 피드백을 추가했습니다.
- 무기 상세 툴팁: 데스크톱은 카드에 마우스 오버 시, 모바일은 카드 탭 시 무기 설명/스탯을 표시합니다.
- 배치 전 범위 프리뷰: 포탑을 선택하면 배치 전에 해당 사거리를 미리 확인할 수 있습니다. (데스크톱: 커서 근처 빈 하드포인트에 단일 프리뷰 / 모바일: 빈 하드포인트 모두에 멀티 프리뷰)
- 사운드 합성: Web Audio 기반 사운드 엔진으로 무기별 사운드를 합성하여 재생합니다.
- 관리자 모드: 무한 자원 및 치트 패널 제공(테스트용).

## 🧭 조작법 (업데이트 반영)
- 공통
  - 클릭/탭: 하드포인트에 포탑 배치 또는 기존 포탑 클릭으로 업그레이드/매각 팝업
  - 숫자키 1..9: 해당 포탑 선택
  - Q / W / E: 스킬(궤도 폭격 / 실드 과충전 / 시공간 왜곡)
  - P / Space: 일시정지 / 재개
  - ESC: 팝업 닫기 / 폭격 조준 취소

- 데스크톱 전용
  - 포탑 카드에 마우스 오버 → 무기 정보 툴팁 표시
  - 포탑 선택 후 캔버스 마우스 이동 → 커서 근처 빈 하드포인트의 사거리 프리뷰(단일)가 표시됩니다.

- 모바일 / 터치
  - 카드 탭 → 포탑 선택 + 정보 패널 토글
  - 포탑 선택 시 빈 하드포인트에 전부 사거리 프리뷰(멀티)가 표시됩니다. 터치 이동 시 해당 위치의 가장 근접 하드포인트 프리뷰로 업데이트됩니다.

## 🧪 테스트 체크리스트
- 모바일에서 주소창 보임/숨김 시 상/하단 HUD와 캔버스 레이아웃이 잘 유지되는지 확인
- 카드 Hover(PC) / Tap(모바일)으로 무기 정보가 정상 표시되는지 확인
- 포탑 선택 → 캔버스에서 배치 전 범위 프리뷰가 정상 동작하는지 확인
- 포탑 업그레이드 시 레벨별 이펙트(시각·음향) 강화가 체감되는지 확인
- 빙동(Freezer) 포탑: 보스·고티어 적에 대해 영구 정지(락다운)가 발생하지 않는지 확인

## ⚙️ 설치 및 실행
- 이 저장소를 클론한 뒤 브라우저에서 `index.html`을 열어 실행하세요. 간단한 HTTP 서버 사용 권장(e.g. `npx http-server` 또는 VSCode Live Server).
- 오디오 재생: 브라우저의 자동 재생 정책 때문에 사운드는 사용자 입력(예: 모드 선택 클릭) 이후에 정상 작동합니다.
