# 🚀 Galaxy Defense: 행성 수호전

외계 함대의 대규모 침공으로부터 행성 본부를 방어하는 순수 HTML5 / Canvas 기반 SF 타워 디펜스 게임입니다.

[![Play Game](https://img.shields.io/badge/PLAY-Galaxy%20Defense-00f0ff?style=for-the-badge&logo=googlechrome)](https://slelic1.github.io/GalaxyDefense/)

---

## 🎮 게임 특징
- **100% 무설치 & 오프라인 구동:** 웹 표준 기술(Canvas & Web Audio API)로 제작되어 PC 및 스마트폰 브라우저에서 즉시 실행됩니다.
- **광고 & 인앱결제 완전 배제:** 순수 게임플레이에 집중할 수 있는 완전 무료 구조.
- **2가지 게임 모드:**
  - **도전자 모드 (Challenger Mode):** 350G로 시작하여 점진적으로 적을 격퇴하고 포탑을 해금/강화하는 정통 디펜스 모드. 5웨이브마다 거대 보스 모선 출현.
  - **관리자 모드 (Admin Mode):** 무한 자원(999,999G), 모든 포탑 5레벨 즉시 풀배치, 치트 패널(전체 섬멸, 웨이브 스킵, 보스 강제 소환, 무적 모드, 3배속 가속) 지원.
- **5종의 방어 포탑:**
  1. `펄스 레이저 (1)`: 빠른 연사의 단일 타겟 레이저
  2. `플라즈마 캐논 (2)`: 광역 폭발 범위 공격
  3. `미사일 발사대 (3)`: 초장거리 유도 로켓
  4. `EMP 충격기 (4)`: 적 이동 속도 65% 감속 전기 충격파
  5. `수리 드론 허브 (5)`: 기지 내구도 및 보호막 지속 복구
- **3종의 전술 스킬:**
  - `Q - 궤도 폭격`: 지정 구역에 대규모 파괴 광선 발사
  - `W - 실드 과충전`: 8초간 기지 완전 무적 및 실드 100% 충전
  - `E - 시공간 왜곡`: 6초간 화면 내 모든 적 이동속도 80% 감속
- **자동 일시정지 (Auto-Pause):** PC 탭 전환, 모바일 앱 전환, 전화 수신, 화면 꺼짐 시 자동 일시정지로 기지 보호.

## 🕹️ 조작법
| 입력 키 / 터치 | 기능 |
| :--- | :--- |
| **마우스 좌클릭 / 터치** | 포탑 설치 / 설치된 포탑 클릭 시 강화·매각 |
| **숫자키 1 ~ 5** | 설치할 포탑 종류 선택 |
| **Q, W, E** | 액티브 스킬 사용 |
| **P / Space** | 일시정지 / 게임 재개 |
| **ESC** | 팝업 닫기 / 폭격 조준 취소 |
